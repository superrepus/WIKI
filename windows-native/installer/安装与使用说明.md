# FoxEss WIKI Windows 安装包

v1.0.0 是 FoxEss WIKI 的首个完整版本。基于 nashsu/llm_wiki v0.6.13，保留原版知识编译、实体分析、跨文档关联与检索，包含完整目录、来源撤回、统计和 API 模型路由增强。本版新导入采用原文件引用：直接读取共享盘或本地原始位置，不把完整原文件复制到知识库；已有数据、项目标识和模型配置保持兼容。

## 安装

1. 在目标电脑用**有共享盘权限的 Windows 账号**登录，双击本发布目录中的 `FoxEss-WIKI-…-x64-Setup.exe`，按向导安装。
2. 首次配置中填写新的本地知识库目录及共享来源目录。模型字段留空时使用“FoxEss 企业默认模型”，首次安装无需填写密钥；也可以填写自己的 Base URL、模型名称和 API Key。
3. 先在企业网络内测试默认模型并确认来源范围。导入、启用同步或恢复队列后，入库会按可用模型继续处理；如果暂不准备入库，可以先不填写来源目录，之后在应用内配置。完整操作请阅读随包的 `FoxEss-WIKI-使用手册.html`，也可在应用顶部打开“使用手册”。
4. “设置 → 来源与自动同步”支持多个额外监控目录，每条目录独立启停并设置周期；首次配置中的共享来源会迁入该列表。手动“＋导入”的文件和“＋文件夹”的目录独立自动检查，不受额外目录开关影响，应用运行并打开对应项目时约每分钟检查变化。支持新增、修改和确认删除后的知识处理；格式、大小及排除规则仍然适用。

需要 Windows 10/11 x64 或兼容的带桌面 Windows Server。包内包含 PDFium、Node.js（供 MCP 使用）、VC 运行 DLL 及微软 WebView2 离线安装程序；运行无需另装 Rust、Node.js、Python、Docker、WSL 或虚拟机。目标服务器的操作系统、企业策略和加密文档解析仍需在该机验收。Server Core 不在本包支持范围。

WebView2 缺失时按微软分发方式安装；内网无须为此联网下载。模型仍需目标电脑能够访问。企业策略限制运行时安装时请由管理员部署 WebView2，不改变系统安全策略。

本包尚未配置企业代码签名证书，Windows 可能显示未签名发布者；需要正式企业分发时可由 IT 对最终安装包进行签名。

## 数据和升级

- 默认程序：`%LOCALAPPDATA%\Programs\FoxEss WIKI`
- 默认新知识库：`%LOCALAPPDATA%\FoxESS\LLMWiki\Data\equipment-wiki`，可在首次配置时指定其他**空的本地目录**。
- 应用配置：`%APPDATA%\com.llmwiki.app\app-state.json`，自定义模型密钥和 API 令牌按原版方式存于本机；企业默认模型仅保存凭据标记，密钥由应用原生层管理、界面不显示。安装包包含内置凭据，可被专业逆向工具提取，仅供授权范围内分发。不得将此配置文件作为公共模板分发。
- 日志：`%LOCALAPPDATA%\FoxESS\LLMWiki\logs`
- 默认 API：`http://127.0.0.1:19828/api/v1`，沿用令牌认证。

“来源与自动同步”页面分别列出始终自动监控的手动来源，以及可以添加多个的额外监控目录。每个额外目录都有独立路径、启用状态、周期和上次扫描时间；停用或移除某条额外配置只取消后续定时扫描，不删除原文件或已入库知识，也不关闭手动来源监控。要撤回知识库对某份来源的使用，请在“原始资料”明确移除。旧单目录配置会保留并迁入列表，无需重新建立知识库。

新导入的共享盘文件、本地文件及文件夹都登记在项目 `.llm-wiki/external-sources.json` 中；`raw/sources/...` 是稳定的来源逻辑路径，在应用文件树和 API 中可见，磁盘上未必有对应的完整原文件。本地保存 Wiki、索引、来源依赖、任务元数据及必要缓存。提取文本、图片和其他缓存可能包含原文内容并占用磁盘空间。

外部来源在应用中只读展示，可以查看真实路径、预览原文并使用系统应用打开原始位置的文件。共享盘或本地原文件继续由用户在原位置维护。临时断连、权限和 I/O 故障会保留登记及现有知识，不当作全部文件已删除；确认原文件删除后才撤回相关知识。移动或改名后需要更新登记或重新导入，并核对旧来源。

在“原始资料”中移除外部来源，只移除引用并撤回关联知识，不删除原始位置的文件；手动移除会留下忽略记录，防止下次扫描又自动添加，明确重新导入可以恢复登记。旧版复制资料和 Wiki 会保留；后续扫描可以沿用旧逻辑来源绑定原文件，必要时将旧本地副本归档到 `.llm-wiki/legacy-sources`，不会删除共享盘原件。

备份或导出知识库**不自动包含外部原文件**。原文件需要单独备份；迁移到另一台电脑时，应恢复同一 UNC 地址及账号权限，或重新定位本地原文件。确定已删除的 Wiki 项目会从最近项目列表清理；暂时不可访问的项目会保留。

已有配置时首次配置器不会覆盖；请在应用中打开已有项目。应用每天按电脑本地时间 06:00 检查 `superrepus/WIKI` 的 GitHub Releases，错过时下次启动或唤醒补查。发现新版本后可以点击“一键更新并重启”：保护编辑与队列、下载并校验签名和哈希、关闭应用、覆盖程序后重启，继续使用已有配置和知识库。更新只对用户点击执行，不会因后台检查而自动安装。开发目录中没有正式安装清单的程序，请先使用完整安装包安装。也可先退出应用，再运行新版安装包手动升级。卸载只删除安装清单中的程序文件、自己的快捷方式和启动项，保留应用配置、知识库及日志；不会递归删除安装目录中用户另放的文件。

**如果电脑已有手工部署和 `FoxESS-EquipmentWiki-Native` 任务，不要同时启动两个部署。** 需要迁移时先停止原应用并禁用原启动任务，再安装、打开现有知识库。保留原项目目录和来源访问权限，既有 Wiki 不需要仅因引用模式变化而全量重新入库。安装器检测到原启动任务启用时不创建竞争的新启动任务。

## 后台运行

安装器为当前账号创建登录触发的 `FoxESS-LLMWiki-<账号SID>` 计划任务；企业策略不允许时回退为当前用户启动文件夹快捷方式。无须提供 Windows 密码。需要 Windows 账号保持登录，不是注销后继续运行的系统服务。

共享盘权限不会随安装包转移；新电脑必须用有权限的账号运行。来源目录不可访问时应保留故障状态，不应把网络断连当作资料全部删除。

## CLI、MCP、Skill

CLI：在程序目录打开 PowerShell：

```powershell
.\wiki.cmd status
.\wiki.cmd catalog -Limit 1000
.\wiki.cmd metrics -Kind ingest
.\wiki.cmd routing
.\wiki.cmd search "产品型号"
```

也可直接调用 `scripts\cli.ps1`，指定 `-Project 项目ID`。CLI 读取本机认证配置后调用统一 API，不读取 Wiki 原文文件。可用 `LLM_WIKI_API_BASE_URL`、`LLM_WIKI_API_TOKEN` 环境变量覆盖连接。

MCP 客户端配置示例（将路径改为安装目录）：

```json
{
  "mcpServers": {
    "llm-wiki": {
      "command": "C:\\Users\\你的账号\\AppData\\Local\\Programs\\FoxEss WIKI\\runtime\\node.exe",
      "args": ["C:\\Users\\你的账号\\AppData\\Local\\Programs\\FoxEss WIKI\\scripts\\mcp-launcher.mjs"]
    }
  }
}
```

启动器从当前账号应用配置读取令牌，并启动原版 MCP 服务。无须将令牌明文复制到 MCP 配置；环境变量可覆盖。MCP、CLI 仍依赖桌面后台进程运行。Skill 原文件附于 `skills\llm-wiki\SKILL.md`，可按所用 Agent 的安装方式添加；安装器不会修改任何已有 Agent 配置。

## 静默安装与运维

```powershell
$wikiSetup = Get-ChildItem -LiteralPath . -Filter 'FoxEss-WIKI-*-x64-Setup.exe' |
  Sort-Object LastWriteTime -Descending | Select-Object -First 1
Start-Process -FilePath $wikiSetup.FullName -ArgumentList '/S' -Wait -WindowStyle Hidden
```

静默安装不自动打开首次配置界面；通过开始菜单运行“首次配置”或“FoxEss WIKI”。`/EXTRACTONLY /S /D=绝对目录` 用于测试解包：不注册启动项、快捷方式或卸载信息，不安装 WebView2，不启动应用。

包内有 `install-manifest.json`；外部 `SHA256SUMS.txt` 用于传输后校验。GPL 源码附于 `source\llm-wiki-corresponding-source.zip`，第三方许可在 `licenses\`；对应源码也在发布目录单独提供。

## 验证范围

请以本发布目录附带的验证汇总和安装包验证结果为准，核对其安装包 SHA256 与实际安装文件一致。验证范围包括相关前端回归、外部原文读取与只读保护、增改删同步、数据兼容、目录隔离以及 CLI/MCP 调用；运行成功的项目和未执行的环境验收会分别记录。另一台 Windows 服务器上的真实共享盘权限、企业加密解析和模型连接仍需在目标机器验证。


## FoxEss WIKI 企业增强版

现有用户的模型配置不覆盖。公开构建不包含企业模型密钥，首次安装时需提供自己的可用模型。企业构建可按管理员选择内置模型凭据，界面和普通配置不展示其原值；包含凭据的客户端仍可被专业逆向提取，不能视为服务器端保密措施。详细操作请打开随包的 FoxEss-WIKI-使用手册.html，或应用顶部的使用手册。

## 发布资产与一键更新

正式仓库为 https://github.com/superrepus/WIKI，最新正式版本入口为 Releases。每个版本包含 `FoxEss-WIKI-<版本>-x64-Setup.exe`、`FoxEss-WIKI-<版本>-update.json`、其 Ed25519 签名 `.json.sig`、`SHA256SUMS.txt`、对应 GPL 源码和离线使用手册。应用只接受固定仓库的更新元数据，并使用内置发布公钥校验签名；传输哈希校验不能替代该签名。发布私钥与企业模型私钥均不能提交到仓库。

自动更新调用安装器 `/S /UPDATE /D=当前安装目录`；该模式不运行首次配置、不改变已有启动偏好、不清空应用设置或项目。外部更新助手在校验文件清单后只备份和替换程序文件，遇到未知用户文件冲突会停止；安装失败时按原清单回滚。卸载依旧保留用户配置和知识库。

`/EXTRACTONLY` 始终优先用于隔离验证，不注册快捷方式、启动项或卸载信息，不启动应用，也不读取真实知识库。

公开无凭据构建不会删除已有模型设置，但原来仅使用“内置凭据”标记的模型需要重新填写实际密钥或切换到其他模型。已有自定义服务地址、模型名和用户自行保存的密钥不会被安装器覆盖。
